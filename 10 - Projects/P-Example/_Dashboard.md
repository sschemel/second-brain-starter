# P-Example

A synthetic sample project, so you can see how a project folder fills up. Copy this folder for each real project (`10 - Projects/P-<Name>/`), then delete this one. The made-up project: **Reading Tracker**, a tiny command-line tool that logs books you've read to a CSV.

Documents live in kind subfolders (`Raw/`, `Research/`, `Plans/`, `Specs/`, `Reviews/`, `Drafts/`, `Assets/`), created only when the first document of that kind is written. Lessons specific to this project go in `Learnings.md`.
