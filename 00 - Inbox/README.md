# 00 - Inbox

A transit zone for quick captures. `/eod` routes everything here to its permanent home and then empties these files.

- `Raw_Captures.md`: anything you jot down during the day
- `Ideas_Backlog.md`: tangents and future ideas, which agents log here silently
- `Learnings.md`: agent corrections, which get folded into `AGENTS.md` at `/eod`
